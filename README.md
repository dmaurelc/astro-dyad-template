# Astro Dyad Template

An [Astro](https://astro.build) editorial-grade starter tailored for [Dyad](https://www.dyad.sh). Built with Astro 7, Tailwind v4, and a type-safe content collection. Ships with a home page, journal (blog), playground, components showcase, and a 404 — all wired to a shared `Layout` with header, footer, mobile menu, and dark-mode toggle.

## Stack

- **Astro 7** — file-based routing, view transitions, server islands
- **Tailwind CSS v4** — `@theme` design tokens, Vite plugin (no PostCSS config)
- **TypeScript 6** — strict mode
- **pnpm** — package manager

## Getting Started

```bash
pnpm install
pnpm dev
```

Open [http://localhost:4321](http://localhost:4321) to see the site.

Other scripts:

```bash
pnpm build      # production build to ./dist
pnpm preview    # preview the production build locally
```

## SEO

Every page emits the full social + crawler surface out of the box:

- **Open Graph + Twitter Card** via [astro-seo](https://github.com/jonasmerlin/astro-seo) — `og:title`, `og:image`, `og:url`, `twitter:card=summary_large_image`, etc.
- **Absolute canonical URL** derived from `Astro.url + Astro.site`.
- **JSON-LD** — `WebSite` + `Organization` on every page, `BreadcrumbList` on nested routes, `BlogPosting` on each article (via the named `jsonld` slot).
- **Sitemap** at `/sitemap-index.xml` (excludes `/404` and any `/draft/*` route).
- **`robots.txt`** at `/robots.txt`, pointing crawlers at the sitemap.
- **Pre-rendered OG images** (1200×630) at `/og-default.png` and `/og/<slug>.png`, generated by `scripts/generate-og.mjs` to match the editorial palette.
- **noindex** on the 404 page.

### Customizing per page

Pass props to `<Layout />`:

```astro
<Layout
  title="My page — Astro Template"
  description="Short, ≤160 chars, used by OG and search."
  image="/og-default.png"
  type="article"             {/* "website" by default */}
  publishedTime={new Date()}
  author="Mira Castell"
  tags={["astro", "design"]}
  breadcrumbs={[
    { name: "Home", href: "/" },
    { name: "Journal", href: "/blog" },
    { name: "Current page" },
  ]}
  noindex                    {/* omit unless this page should not be indexed */}
>
```

Add page-level JSON-LD via the named `jsonld` slot:

```astro
---
import JsonLd from "../components/JsonLd.astro";
import { buildArticleJsonLd } from "../lib/seo";
---

<Layout title="…">
  <JsonLd slot="jsonld" data={buildArticleJsonLd(article, articleUrl)} />
  <article>…</article>
</Layout>
```

### Regenerating OG images

After editing `scripts/articles-meta.mjs` (the OG-relevant fields mirror of `src/lib/articles.ts`):

```bash
pnpm og:generate
```

PNG output goes to `public/og/<slug>.png` and `public/og-default.png`. Files are committed to the repo so clones ship working OG cards without needing `sharp` installed.

### Updating the site URL

`SITE.url` lives in [src/lib/site.ts](src/lib/site.ts). It's duplicated inline in `astro.config.mjs` because Astro config cannot import TS. Change both in lockstep.

## Features

- **Dark mode** — persisted via `localStorage`, respects `prefers-color-scheme` on first visit, no FOUC.
- **Mobile menu** — slide-in drawer with focus trap and `Escape` to close.
- **Type-safe content** — Astro content collections validate frontmatter with Zod.
- **View transitions** — enabled in `Layout.astro` for SPA-feel navigation.
- **Component showcase** — `/components` renders every primitive in isolation.
- **Playground** — `/playground` for tweaking tokens and ad-hoc UI experiments.
